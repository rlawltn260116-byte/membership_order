## 사용자 확정 규칙 (2026-11-16)

1. `발주처(제조처)`의 괄호 밖을 실제 발주처·매입처로, 괄호 안을 제조처로 저장한다. 괄호가 없으면 제조처는 빈 문자열이다.
2. `닛신(티에이치케이컴퍼니)`, `미라클메디(티에이치케이컴퍼니)`, `해련(안앤락)`은 거꾸로 적힌 예외다. 앞의 두 건은 티에이치케이컴퍼니, 마지막은 안앤락에 발주한다. 닛신·미라클메디·해련은 제조처다.
3. `조아(시호넨스)`는 제외한다.
4. `티에치케이컴퍼니`는 `티에이치케이컴퍼니`, `사과나무COP`는 `사과나무코퍼레이션`으로 통합한다. `명성H`와 `명성실버케어`는 구분한다.
5. 매입처 끝의 ` / 직배`는 해석할 때 제거하고 원본 표기는 `rawSupplier`에 보존한다.
6. 발주처를 `direct-delivery-schedule.json`의 업체명과 연결한다. 티에이치케이컴퍼니만 명시적 별칭으로 `THK`(앱 표기 이로움)에 연결한다. 다른 이름을 유사도나 제조처로 추측하여 연결하지 않는다. 시간표 밖의 발주처는 `scheduleVendor: "미정"`, `scheduleStatus: "발주 시각·방식 미정"`으로 남긴다. 시간표의 여러 회차 중 한 회차를 이 자료에서 임의로 고르지 않는다.

비급여·중고 시트의 `매입처(공급처)`도 위 사용자 확정 규칙으로 해석한다.

| 적용 규칙 | 행 수 |
| --- | ---: |
| 발주처·제조처 역전 보정 | 5 (닛신 2, 미라클메디 2, 해련 1) |
| 업체명 별칭 통합 | 15 (티에치케이컴퍼니 14, 사과나무COP 1) |
| 끝 직배 표기 제거 | 6 |
| 시간표 THK 연결 | 64 |

매입처 보정은 26행이다. THK 연결까지 포함하면 규칙 적용 행은 68행, 중복 적용을 포함한 규칙 적용 횟수는 90회다. 제외한 2행은 학습 행과 규칙 적용 행 집계에서 빠진다.

시간표 미정 29개 발주처: 남양금속, 다원엠디, 디엠씨, 레머디랩, 명성H, 사과나무코퍼레이션, 삼한메디, 시선, 신동아이에스, 에스제이, 에이블라이크, 에코드림, 엔에스비에스, 영화의료기, 올비트앤, 이노팩트, 제이엠메디칼, 지크린텍, 지후마켓, 케어메이트, 케어썸, 코지케어, 태양메디텍, 평화양행, 포디엠, 폴리텍, 한마음케어, 해올, 현대의료산업사.

## 생성과 공개 필드

```powershell
& 'C:/Users/woori/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe' -X utf8 tools/build_supplier_map.py '<로컬 원본 xlsx 경로>'
```

`--schedule`과 `--output`으로 입력 시간표와 출력 경로를 바꿀 수 있다. 원본은 읽기 전용으로 열고 저장하지 않는다. 필수 시트 누락·숨김, 필수 머리글 누락, 모델이 있는 행의 필수 칸 누락과 잘못된 매입처 괄호는 오류로 중단한다.

| 시트 | 구분 | 읽는 열 |
| --- | --- | --- |
| 급여 상품 공급 가격표 | 급여 | 품명, 모델명, 매입처(제조처) |
| 비급여 상품 공급 가격표 | 비급여 | 품명, 모델명, 매입처(공급처) |
| 중고 상품 공급 가격표 | 중고 | 품명, 모델명, 매입처(공급처) |

숨김 `Sheet1`, 부품·침대 부품·반품 시트는 읽지 않는다. 데이터 행에는 `model`, `modelKey`, `category`, `productName`, `supplier`, `manufacturer`, `scheduleVendor`, `scheduleStatus`, `rawSupplier`, `appliedRules`만 넣는다. 단가·가격·마진·택배비, 급여코드, 내부 ERP 코드, 원본의 로컬 경로, 연락처·비밀값은 저장하지 않는다. 상위 `summary`의 숫자는 모델·행·업체·규칙 건수다. 모델명에 포함된 숫자·규격은 그대로 보존한다.

## 모델명으로 조회

독립 모듈 `worker/order-runner/supplier-map.mjs`는 파일 읽기와 조회만 제공한다.

```javascript
import { lookupSupplier } from './worker/order-runner/supplier-map.mjs';
const result = lookupSupplier('수동휠체어 miki-w ah 오렌지');
// result.status: 'matched', result.supplier: '미키코리아메디칼'
```

유니코드 NFKC 정규화, 소문자화, 공백과 소괄호·대괄호·중괄호 기호 제거를 적용한다. 괄호 안 내용, 하이픈, 상품 종류, 색상·규격, 중고 표기는 유지한다. 예를 들어 `수동휠체어 MiKi-W AH (오렌지)`와 위 조회는 같지만, `MiKi-W AH`만 입력하는 부분 검색은 하지 않는다. 원본 모델명 열에 포함된 상품 종류도 조회에 포함해야 한다.

결과에는 `status`, `modelKey`, `supplier`, `suppliers`, `matches`가 있다. 발주처가 하나면 `matched`, 서로 다른 발주처가 둘 이상이면 `ambiguous`와 `supplier: null`, 없으면 `not_found`와 `supplier: null`이다. 정확 표기로 조회해도 정규화 키에 복수 발주처가 있으면 모호함으로 반환한다. 같은 업체의 여러 구분 행은 모호함으로 보지 않는다.
