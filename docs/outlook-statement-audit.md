# Outlook 명세서 양식·특이 사례 검수 — 2026-11-09

시간표 JSON의 이메일 17회차에서 중복을 제거한 14개 업체를 대상으로, 사용자가 로그인한 회사 Outlook의 지정 공용 사서함을 조사했다. 사용자는 메일 열기로 읽음 상태가 바뀌는 것을 허용했다. 이후 추가 지시에 따라 정상 자료는 대표 양식을 확인하고, 정정·반품·분할 납품·합산 문서·중복 후보 등 **자동 처리를 막는 특이 사례 발견에 집중했다.**

업체별 검색 결과에서 본문을 확인한 대화 식별값의 **업체별 귀속 합계는 242개, 업체 간 중복을 제거한 고유 식별값은 236개**다. 일부는 검색어에 걸렸을 뿐 해당 업체가 보낸 메일이 아니다. 무관 메일 귀속 기록 11개에는 공공기관 안내·사내 문의·다른 물류업체 정산 등이 포함되며, 나이스텍 7개 중 3개·건강홈케어 5개 중 2개·포웰 19개 중 3개 등이 해당한다. 미키코리아와 미키코리아메디칼은 같은 명세 메일 하나를 공유한다. 이 수치는 업체별 실제 수신 메일 수나 고유 명세서 수가 아니다. 발주서·회신·원장 요청·세금계산서·판매현황·송장 안내도 섞여 있다. 실제 조회 문서, 내려받은 PDF·JPG와 원문 위치는 `.local-analysis/outlook-statement/`에 보관했다. 아래 빈도는 검수 표본 안에서 확인한 수치이며 전체 업체의 발생률로 확대하지 않는다. HTML 빈도는 품목 행·일련번호·머리글의 추출내용이 동일한 재관찰을 제거한 75표본 기준이다. 같은 명세의 다른 버전은 서로 다른 내용 표본일 수 있으므로 고유 명세서 수로 쓰지 않는다.

**업체별 수백 건 전수 검수와 전체 고유 명세서 건수 확정은 완료하지 못했다.** 진산메디칼 상세 뷰어는 중간 창이 닫힌 뒤 최종 조회 창을 확보하지 못했다. 나이스텍·건강홈케어·코리아케어서프라이에서는 검수한 검색 결과만으로 개별 거래명세서 대표 양식을 확보하지 못했다. 이 경우 미확인을 정상 또는 예외 0건으로 처리하지 않는다.

HTML 표는 제목·표 머리글·행과 합계를 확인했다. 이카운트와 WEHAGO는 메일 첨부가 없어도 외부 링크에 명세서가 있는 유형이다. WEHAGO 대표 조회에는 원문에 있는 공급받는 회사의 사업자번호 확인이 필요했으며 비밀번호를 입력하거나 계정 권한을 바꾸지 않았다.

## 자동화 입력 설계에 반영할 사항

1. 메일, 문서, 조회 쪽, 인쇄 쪽, 품목 행을 별도 단위로 보관한다. 메일 제목의 `외 N건`, 첨부 수, 조회 쪽 수를 명세서 건수로 쓰지 않는다. 원본·추출값·수정 이력·원문 위치를 유지한다.
2. 문서별로 거래일·작성일·발급시각·수신시각을 분리한다. 월간 합산을 당일 납품 1건으로 등록하지 않는다. 품목 행 수와 상품 수량도 구분한다.
3. 상품 행과 운임·할인·반품 행, 공급가액·세액·총액, 쪽별 소계·문서 총계·미수잔액을 구분한다. VAT 포함 단가를 공급가액과 단순 곱셈 비교하지 않는다. 원 단위 배분 규칙이 확인되기 전 숫자를 자동 보정하지 않는다.
4. 품명에 붙은 바코드·수취인·옵션, `개`·`SET`·소수 수량, 바코드 목록·범위, 비어 있는 송장을 각각 보존한다. 확인한 품목 대응표·단위 규칙 없이 문자열을 임의 분리하거나 묶지 않는다.
5. 수신자·주소·품목·수량 네 값이 모두 맞는 기존 주문이 정확히 하나여야 자동 연결한다는 기존 규칙을 유지한다. 회사 주소를 배송지로 대체하거나 이름·송장만으로 주소를 추측하지 않는다. 주소 누락·복수 주문·부분 납품·월간 집계·정정·음수·중복 후보는 보류한다. 명성실버케어처럼 네 값이 있는 양식도 실제 발주서 대조 통과 전에는 자동 연결 완료로 표시하지 않는다.
6. 이카운트 메일에는 수신 후 3개월이 지나면 문서를 볼 수 없다는 안내가 있었다. 링크형도 원본 파일·화면·추출값을 수신 시점에 보관하는 경로가 필요하다. 오래된 링크가 열리지 않은 경우 자료 없음으로 처리하지 않는다.

자세한 등록 전 조건은 [명세서 기반 자동화 설계](amaranth-statement-automation.md)에 연결했다. 실제 발주, 메일 발송·회신·전달·삭제·이동·플래그·분류 변경, 아마란스 저장은 수행하지 않았다. 메일 열기에 따른 읽음 상태 변경 외의 업무 처리를 하지 않았다.

## 이전 목록 조사와 남은 범위

직전 조사에서는 19개 검색의 `명세` 키워드 일치 행 합계가 1,529였다. 안앤락 524, 포웰 307, 명성실버케어 276, THK 187, 베스타 111, 삼원스카이 42, 미키코리아 32, 진산 28, 포에버 11, 엠씨텍 10, 미키코리아메디칼 1이었고, 나이스·코리아케어·건강홈케어의 `명세` 조합은 0행이었다. 업체명 단독 검색에서는 추가 결과가 있었다. 이 합계는 검색어 간 중복·대화 묶음·비명세서가 제거된 수치가 아니며 고유 명세서 수로 쓰지 않는다.

이전의 ‘읽지 않음 표시여서 열지 않았다’는 접근 제한은 이번 사용자 승인으로 해제됐다. 이전 0행 검색 일부는 이전 결과 화면 잔존 가능성을 배제하지 못했으므로 미수신 근거로 쓰지 않는다. 이번 조사는 실제 본문과 대표 자료를 확인한 표본 조사이며, 회사 계정의 커넥터 관리자 승인·무인 자동 수신 연동은 여전히 미완료다.

남은 일은 진산메디칼 상세 명세서 확보, 대표 명세서가 없는 3개 업체의 원본 확보, 업체별 추가 표본 확대와 고유 문서·버전·중복 발송의 확정 집계, 원래 발주서와의 실제 연결 대조, 단위·세금·운임 배분 규칙 확인이다. 모든 원본·첨부·추출 결과·수급자·주소·연락처는 Git 제외 경로 `.local-analysis/`에만 두며 공개 문서에는 구조와 집계만 남겼다.
