# 취합 엑셀 이후 발주 준비

주문 취합은 사람이 계속 수행한다. `tools/prepare_direct_orders.py`는 완성된 취합 엑셀을 읽어 발주 준비물만 로컬에 만든다. 아마란스 취합 도구나 운영 주문 워커에는 연결하지 않는다. 로그인, 사이트 접속, 주문 제출, 메시지 발송, 예약 실행 기능은 없다.

Python과 `openpyxl`이 필요하다. 현재 입력은 `.xlsx`만 지원하며, 구형 `.xls`는 원본을 보존하고 별도 `.xlsx`로 저장한다.

```powershell
python -B tools/prepare_direct_orders.py 'C:/업무/20261007_직배(미키코리아) 발주서.xlsx' --output .local-analysis/prepared-orders/검토-001
python -B tools/prepare_direct_orders.py 'C:/업무/여러업체.xlsx' --sheet 발주 --output .local-analysis/prepared-orders/검토-002
```

출력 폴더는 매 실행 새 이름을 사용한다. 기존 결과를 덮어쓰지 않으며, 프로젝트 `.local-analysis/` 바깥에는 결과를 저장할 수 없다. 실제 고객정보·연락처·가격·ERP 코드를 포함할 수 있는 입력 및 결과를 Git에 추가하지 않는다.

파일명의 `THKC`는 시간표의 `THK`로 인식한다. 업체는 명시적 `--vendor`, `업체` 열, 파일명의 `직배(업체명)` 또는 `직배 (업체명)` 순서로 선택한다. 시간표 업체명과 정확히 일치해야 하며 품명으로 업체를 추측하지 않는다. 명시 인자가 파일명보다 우선하되 업체 열과 명시 인자/파일명이 충돌하면 보류한다. 보고서에 인식 근거를 기록한다. 한 파일에 여러 업체가 있으면 `업체` 열로 나눈다.

시트가 하나면 자동 선택한다. 여러 시트는 `--sheet`가 필수다. 숨김 시트·행·열은 보류한다. 주문번호, 납품처, 납품처전화번호, 품명, 주문수량 열을 필수로 검사한다. `비고(내역)`은 업무 의미를 판정하지 않고 초안에 그대로 싣되, 보고서의 `rowsWithNotes`로 표시해 담당자가 확인한다. 수식은 저장된 계산값을 신뢰하지 않고 보류하며, 수량은 양의 정수여야 한다. 같은 주문·납품처·품목·수량이 중복되면 자동 합산하거나 삭제하지 않는다.

표준 머리글이 없는 업체 양식은 보류한다. 명시적 열 매핑은 `--mapping <로컬 JSON 경로>`로 제공할 수 있다. JSON은 표준 필드명을 실제 엑셀 머리글에 연결하는 객체다. 예를 들어 `"품명": "제품명"`을 사용하되 필수 필드 전체를 매핑해야 한다. 현대메딕스 등 별도 출력 양식이 필요한 업체는 매핑만으로 출력 양식이 검증되지 않으므로 계속 보류한다. 참조 카탈로그의 품목·옵션을 자동 상품 매핑으로 사용하지 않는다.

`report.json`에서 업체별 전체 행, 보류 사유, 시간표의 모든 회차와 발주수단을 확인한다. 한 업체의 행 하나라도 보류면 그 업체의 준비물을 전부 만들지 않는다. 정상 업체에만 다음 파일을 생성한다.

- 이메일: 수신처를 비워 둔 `email-draft.txt` 초안
- 팩스: 브라우저에서 검토·인쇄할 `fax-print.html`
- 카톡: 붙여넣기 전 검토할 `kakao-draft.txt`
- B2B몰·ERP: `input-values.json`과 수동 확인 목록

모든 결과는 미발송 드라이런이다. 정상 상태 `PREPARED_DRY_RUN`은 실제 제출 승인이 아니다. 마감 미등록 업체는 보류하고, 등록 업체도 공휴일·회차·당일 마감 경과 및 접수 여부는 사람이 확인한다. B2B 상품·ERP 품목코드, 옵션, 가격, 배송비는 자동 확정하지 않는다. 실제 발주는 기존 승인 절차와 제출 잠금을 그대로 따른다.

종료 코드 `0`은 준비물 생성, `2`는 업무상 보류다. 두 경우 모두 로컬 보고서를 먼저 검토한다. 입력 오류나 새 출력 폴더 생성 실패 등 실행 오류는 별도 실패로 처리한다.

검증: `python -B tools/test_prepare_direct_orders.py` (실제 고객정보 없는 모의 OOXML 입력).
